## описание игры

ППК - новелла с нелинейным сюжетом, в ней помимо забавных моментов
поднимаются тяжёлые темы, где всё не так однозначно на первый взгляд.
Не рекоммендуется людям с повышенной чувствительностью к тяжёлым темам

### особенности игры

- психоделичесский нарратив, полный пирамидальных словесных конструкций
- стилизованная пикселная графика совмещённая с артами
- высокая вариативность: каждое прохождение уникально. При этом некоторые
  реплики и сцены имеют шанс на повторение и/или появление. Вам придётся
  по-настоящему сблизится с героем чтобы узнать всё что он скрывает
- разношёрстные саундтреки некоторые имеющие гнетущую и вязкую атмосферу

управление:
- F4 - переключение в полноэкранный/оконный режим
- ESC - меню паузы

минимальные системные требования:
- ОС - Linux/Windows 64-битная ; Windows 10+ ; Linux ядра 6.12+
- Процессор: любой, новее 2019 года
- ОЗУ - 2гб свободной памяти
- Места на диске - 600Мб
